# 漚汪國小探索園區｜校園慢跑運動 3D 校園特色互動模型

> **Tainan Municipal Jiangjyun District Ouwang Elementary School**  
> 臺南市將軍區漚汪國民小學 3D 校園特色探索網站——以校園實體空間為核心，透過可自訂裝扮的慢跑小隊運動穿梭於 PU 跑道、前庭三合院校舍、光電球場與八大特色站點，完整整合校園特色課程、111–114 學年度榮譽事蹟與 64 篇歷年媒體報導。

---

## 🌟 核心設計特色

### 1. 校園微縮 3D 實景與農村外圍地景（`scene3d.js`）
- **中央 PU 環校跑道與綠茵操場**：6 道 PU 合成橡膠環狀跑道上有恆速分道慢跑學生；中央草坪配置學童傳接足球互動與滾動足球；跑道北側設有司令台建築（依校園視角簡潔呈現，不設置旗桿與國旗）。
- **將軍胡蘿蔔田野與白鷺鷥飛翔**：校園實景穩固接地不漂浮，外圍環繞多塊紅蘿蔔農田與戴草帽農友，高空有雙層動態振翅白鷺鷥群盤旋掠過。
- **實體無穿牆避障與精緻材質**：建築窗面、太陽能光電板、羽毛球場地墊、太陽能光電籃球場與戶外 LIVE 電視牆均採用程式化 CanvasTexture 與非共面立體幾何，搭配全面人物間距與路徑防碰撞校正。

### 3. 慢跑分身裝扮與定點導覽停靠（`app.js` / `scene3d.js`）
- **自由客製慢跑分身**：右下角「🎨 慢跑分身裝扮」提供 **6 色運動服**、**4 種頭飾**（運動頭帶、活力球帽、田園草帽、無頭飾）與 **8 種隨身道具**（接力棒、羽球拍、說書繪本、太鼓棒、**手風琴**、榮耀金盃、小記者相機、活力雙手），即時反映於場中慢跑主分身。
- **定點停靠正面互動卡**：跑者小隊沿環校無障礙路線慢跑抵達各站正面時，自動停靠並面向使用者顯示站點重點摘要卡（`#runner-stop-card`）；點擊「🏃 關閉介紹・繼續跑往下一站 ▶」後即關閉卡片並接續慢跑前往下一站，亦可直接開啟「📖 查看完整介紹」。

### 4. 多重視角、全頁清單與三段天色切換（`app.js` / `index.html` / `styles.css`）
- **視角與頁面切換**：底部工具列支援 **全景**、**鳥瞰**、**🏃 陪跑視角**、**📰 媒體專區**、**全頁清單**，其中「全頁清單」頁首附有 **「🏃 返回 3D 園區」** 按鈕（亦支援 `Esc` 鍵返回）。
- **白天／黃昏／夜晚模式**：預設以明亮 **☀️ 白天** 呈現，可隨時於底部工具列一鍵切換 **🌇 黃昏**（金黃暖陽與微亮校舍窗景）或 **🌙 夜晚**（深藍夜色與明亮點燈窗景）。
- **即時天氣與雨晴系統**：頂部資訊欄顯示目前時間並串接 Open-Meteo API 取得臺南將軍即時氣溫與天候狀態，同步連動 3D 天空雲朵與降雨粒子動畫。
- **64 篇媒體報導分類總覽**：收錄校網全部 64 篇平面與網路媒體報導（涵蓋中華日報、臺灣時報、自由時報、國語日報、聯合新聞網、中時新聞網、ETtoday 新聞雲、臺南市政府、廣達文教基金會、民眾網、Yahoo 新聞共 11 家媒體），依【🥕 食農與生態】、【💡 課程創新與走讀】、【💛 品格與謝師感恩】、【🎨 藝文雙語與競賽】、【❤️ 公益關懷與獎學金】、【🏫 110校慶與校園盛事】六大主題分類整理，支援關鍵字搜尋、出處篩選、原文開啟與一鍵飛往對應 3D 站點。

## 📁 專案結構

```text
d:\漚汪特色\output\
├── index.html          # 主網頁架構（進場畫面、3D 畫布、左側站點清單、全頁清單、媒體總覽、分身裝扮卡與工具列）
├── styles.css          # 溫暖手作紙感 UI、燈箱、卡片排版與 RWD 響應式樣式
├── data.js             # 八大特色站點內容、3 項立體模型圖鑑資料、15 筆榮譽榜與 64 篇分類媒體報導
├── scene3d.js          # Three.js r128 校園 3D 引擎（PU 跑道操場、足球草坪、外圍蘿蔔田野、白鷺鷥、八大站點與慢跑小隊）
├── app.js              # UI 狀態管理、分身換裝、全頁清單／媒體總覽篩選、天色切換、Open-Meteo 天氣串接與相片燈箱
├── README.md           # 本專案說明文件
└── assets/
    └── images/         # 25 張校園實景照片 (img_01.jpg ~ img_25.jpg) 與 3 張校區微縮模型圖 (campus_model_*.jpg)
```

## 🚀 本機執行方式

本專案為純前端靜態網頁（HTML + CSS + JavaScript + Three.js CDN），可直接以任一本機靜態伺服器開啟 `index.html` 瀏覽體驗：

```powershell
cd d:\漚汪特色\output
# 擇一使用任一靜態伺服器工具，例如 VS Code Live Server / npx serve / Python http.server
```
