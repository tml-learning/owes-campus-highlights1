## 🌟 核心設計特色

### 1. 校園微縮 3D 實景與農村外圍地景（`scene3d.js`）
- **中央 PU 環校跑道與綠茵操場**：6 道 PU 合成橡膠環狀跑道上有恆速分道慢跑學生；中央草坪配置學童傳接足球互動與滾動足球；跑道北側設有司令台建築（依校園視角簡潔呈現，不設置旗桿與國旗）。
- **將軍胡蘿蔔田野與白鷺鷥飛翔**：校園實景穩固接地不漂浮，外圍環繞多塊紅蘿蔔農田與戴草帽農友，高空有雙層動態振翅白鷺鷥群盤旋掠過。
- **實體無穿牆避障與精緻材質**：建築窗面、太陽能光電板、羽毛球場地墊、太陽能光電籃球場與戶外 LIVE 電視牆均採用程式化 CanvasTexture 與非共面立體幾何，搭配全面人物間距與路徑防碰撞校正。

### 3. 慢跑分身裝扮、前瞻運鏡與兩階段漸進式底部抽屜（`app.js` / `scene3d.js` / `styles.css`）
- **自由客製慢跑分身**：右下角「🎨 慢跑分身裝扮」提供 **6 色運動服**、**4 種頭飾**（運動頭帶、活力球帽、田園草帽、無頭飾）與 **8 種隨身道具**（接力棒、羽球拍、說書繪本、太鼓棒、**手風琴**、榮耀金盃、小記者相機、活力雙手），即時反映於場中慢跑主分身。
- **陪跑前瞻視角（Look-Ahead Offset）與進度感知**：
  - **鏡頭前瞻偏移**：慢跑移動期間，鏡頭注視點取跑者當前位置與下一站目標點之間 **36% 插值點**，並拉高微微俯視，使跑者位於畫面偏下方、中上方自然帶出目標站點建築。
  - **頂部輕量跑道進度條（Mini Progress Pill）**：即時顯示「`🏃 正在前往：第 X 站 — 站點名稱（距離 XXm）`」與 **1～8 站小圓點進度**（可點擊切換目標站）。
  - **3D 空間呼吸光柱與浮動目標指標（3D Waypoint Marker）**：於目標站點上方建立垂直呼吸光柱、擴散光環、旋轉晶體與 `🎯 目標` 浮動站牌高亮。
- **手機直式螢幕全景視野補償（FOV & Screen-Space Offset）与環繞慢速運鏡（Gentle Orbit）**：
  - 偵測窄螢幕（`window.innerWidth < 768` 或 `aspect < 1`）自動補償放大垂直 FOV 並將抵達站點鏡頭距離拉遠 **1.42 倍**；同時將鏡頭注視點往 Y 軸下方偏移，讓微縮站點建築與跑者落在**手機螢幕上半部 45% 黃金視野區**，並於停靠時自動進行 **$\pm 15^\circ$ 正弦慢速環繞運鏡**。
- **輕量底部預覽小卡（Peek Bar）與自動收合面板**：
  - **抵達前 1.2 秒賞景緩衝 → 輕量預覽小卡 Peek Bar**：跑者停靠後先保留 1.2 秒純賞景推進，隨後底部浮現高約 `115px～122px` 的輕量預覽小卡（僅顯示編號、站名、一句亮點摘要與「`🏃 繼續跑下一站 ▶`」按鈕，不顯示展開詳細介紹），保留 80% 以上無遮擋 3D 景觀。
  - **慢跑移動中自動收合所有面板**：點擊「`🏃 繼續跑下一站 ▶`」或切換視角時自動收合所有面板，將畫面 100% 還給慢跑視角。

### 4. 多重視角、全頁清單與響應式介面（`app.js` / `index.html` / `styles.css`）
- **精簡視角與全頁清單**：底部工具列保留 **全景**、**鳥瞰**、**🏃 陪跑視角**、**全頁清單**、**站名** 與 **暫停／播放**，其中「全頁清單」頁首附有 **「🏃 返回 3D 園區」** 按鈕（亦支援 `Esc` 鍵返回）。
- **固定明亮白天與響應式設計（RWD）**：全天候固定以明亮晴朗 **☀️ 白天** 光影呈現（已精簡移除黃昏、夜晚及右上時間天氣顯示），並針對桌面、平板與手機重新規劃響應式版面與提示文字安全位置，確保彈出摘要卡與提示訊息不遮擋按鈕。
- **64 篇媒體報導分類總覽**：透過左側清單「📰 64 篇媒體報導分類總覽」或「媒體報導站」進入，收錄校網全部 64 篇平面與網路媒體報導（涵蓋中華日報、臺灣時報、自由時報、國語日報、聯合新聞網、中時新聞網、ETtoday 新聞雲、臺南市政府、廣達文教基金會、民眾網、Yahoo 新聞共 11 家媒體），依【🥕 食農與生態】、【💡 課程創新與走讀】、【💛 品格與謝師感恩】、【🎨 藝文雙語與競賽】、【❤️ 公益關懷與獎學金】、【🏫 110校慶與校園盛事】六大主題分類整理，支援關鍵字搜尋、出處篩選、原文開啟與一鍵飛往對應 3D 站點。


```powershell
cd d:\漚汪特色\output
# 擇一使用任一靜態伺服器工具，例如 VS Code Live Server / npx serve / Python http.server
```
